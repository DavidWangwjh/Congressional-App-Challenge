# Task 2: Identify User Flows

## What is a User Flow?
A **user flow** describes how a user moves through a website or app to complete a task.

It usually includes:
- The **starting screen**
- The **action the user takes**
- The **next screen they reach**

Think of it as the **path a user follows**.

### Example
Home Page → Click "Login" → Login Page

---

## Your Task
Identify **3 different user flows** on the website you chose.

For each user flow, include:

1. **Starting screen**
2. **User action** (what the user clicks/taps/types)
3. **Resulting screen**

### Example

**User Flow 1**
Home Page → Click "Sign Up" button → Account Creation Page

**User Flow 2**
Home Page → Click "Products" → Product List Page

**User Flow 3**
Product Page → Click "Add to Cart" → Shopping Cart Page
