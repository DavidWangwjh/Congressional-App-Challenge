HTML Tags Demo

This page is a clean classroom demo that shows common HTML tags and explains what each one does.

How to use this page

Each section below shows:

  • the name of the HTML tag
  • what the tag does
  • an example of how it looks on the webpage
  • the code used to create it
<h1> to <h6> — Headings

Heading tags are used for titles and section names. <h1> is the biggest heading and <h6> is the smallest.

This is an h1 heading

This is an h2 heading

This is an h3 heading

This is an h4 heading

This is an h5 heading
This is an h6 heading
<h1>This is an h1 heading</h1> <h2>This is an h2 heading</h2> <h3>This is an h3 heading</h3> <h4>This is an h4 heading</h4> <h5>This is an h5 heading</h5> <h6>This is an h6 heading</h6>
<p> — Paragraph

The paragraph tag is used for normal text on a webpage.

This is an example paragraph. It is used for writing sentences and information on a page.

<p>This is an example paragraph.</p>
<br> — Line Break

The line break tag moves text to the next line without starting a new paragraph.

This is the first line.
This is the second line after a line break.

<p> This is the first line.<br> This is the second line after a line break. </p>
<hr> — Horizontal Rule

The horizontal rule tag adds a line across the page. It is often used to separate sections.

<hr>
Text Formatting Tags

These tags change the appearance or meaning of text.

<b> makes text bold.

<strong> shows important bold text.

<i> makes text italic.

<em> emphasizes text, usually italic.

<u> underlines text.

<mark> highlights text.

<small> makes text smaller.

<del> shows deleted text.

H2O uses <sub> for the small 2.

23 uses <sup> for the raised 3.

<b>Bold text</b> <strong>Important text</strong> <i>Italic text</i> <em>Emphasized text</em> <u>Underlined text</u> <mark>Highlighted text</mark> <small>Small text</small> <del>Deleted text</del> H<sub>2</sub>O 2<sup>3</sup>
<a> — Link

The anchor tag creates a clickable link. The href attribute tells the browser where to go.

Visit GitHub

<a href="https://github.com" target="_blank">Visit GitHub</a>

<ul>, <ol>, <li> — Lists

Use lists to organize items. <ul> creates bullet points, <ol> creates numbered lists, and <li> is each list item.

Unordered List

  • HTML
  • CSS
  • JavaScript

Ordered List

  1. Open VS Code
  2. Create index.html
  3. Write code

Tables are used to organize information into rows and columns.

<div> and <span>

<div> is a block container used to group larger sections. <span> is an inline container used for small parts of text.

This is a div. It groups a block of content together.

This sentence has a span tag inside it.

<div>This is a div.</div> <p>This sentence has a <span>span tag</span> inside it.</p>
Form Tags

Forms collect information from users. Common form tags include <form>, <label>, <input>, <textarea>, <select>, and <button>.

Semantic Tags

Semantic tags help describe the meaning of different parts of a webpage. They make code easier to read and organize.

<header>

This is the top section of a page or section.

<nav>
Home Projects Contact
<main>

This is the main content of the page.

<section>

A section groups related content.

<article>

An article is a complete piece of content.

<aside>

An aside contains extra information.

<footer>

This is the bottom section of a page.

<header>...</header> <nav>...</nav> <main>...</main> <section>...</section> <article>...</article> <aside>...</aside> <footer>...</footer>
<code> and <pre> — Code Display

<code> is used to show code. <pre> keeps the spacing and line breaks exactly as written.

Inline code example: <h1>Hello</h1>

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
<p>Inline code example: <code>&lt;h1&gt;Hello&lt;/h1&gt;</code></p> <pre><code> <ul> <li>Item 1</li> </ul> </code></pre>
<!-- comment --> — HTML Comment

Comments are notes for people reading the code. They do not appear on the webpage.

You cannot see the comment on this page, but it exists in the HTML file.

<!-- This is an HTML comment -->
