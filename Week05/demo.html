Part 3: Colors

CSS lets us change the color of text and the background of elements.

1. Color Names

This text uses a color name: red.

.color-name-example { color: red; }

2. HEX Colors

This text uses a HEX color: #1e90ff.

.hex-example { color: #1e90ff; }

3. RGB Colors

This text uses an RGB color: rgb(34, 139, 34).

.rgb-example { color: rgb(34, 139, 34); }

4. Background Color

This paragraph has a background color.

.bg-color-example { background-color: #fff3b0; padding: 10px; }

5. Combining Text Color and Background Color

This text is white on a dark background.

.combo-color-example { color: white; background-color: #333; padding: 10px; }

2. Font Family

4. Text Alignment

5. Text Decoration

This text is underlined.

Part 5: Spacing

Spacing makes websites easier to read. The most common spacing properties are margin and padding.

1. Margin

Margin is the space outside an element.

This box has margin: 20px;
.margin-example { margin: 20px; background-color: #ffd6d6; padding: 10px; }

2. Padding

Padding is the space inside an element.

This box has padding: 20px;
.padding-example { padding: 20px; background-color: #d9f7be; }

3. Border

A border adds an outline around an element.

This box has a border.
.border-example { border: 3px solid #555; padding: 10px; }

4. Margin + Padding Together

Many elements use both margin and padding.

This box has margin, padding, border, and background color together.
style=" margin: 20px; padding: 20px; border: 2px solid #888; background-color: #fff0f6; "

Part 6: Units

CSS uses units to define size. Different units are useful in different situations.

1. Pixels (px)

This text uses 24px.

Pixels are fixed sizes.

.units-px { font-size: 24px; }

2. Percent (%)

Percent is relative to the parent element.

This box is 50% of the parent width.
.units-percent-box { width: 50%; background-color: #cfe2ff; padding: 10px; }

3. em

em is relative to the font size of the parent element.

Parent text is 20px.
This child text is 1.5em, so it becomes larger.
.units-em-parent { font-size: 20px; } .units-em-child { font-size: 1.5em; }

Bonus Review: CSS Selectors

Selectors choose which HTML elements the CSS should style.

1. Element Selector

This paragraph is targeted by the p selector.

All paragraph tags inside this section are affected.

.selector-demo p { color: #444; }

2. Class Selector

This paragraph uses the class highlight.

.selector-demo .highlight { color: #d63384; font-weight: bold; }

3. ID Selector

This heading uses the id "special-title"

.selector-demo #special-title { color: #0d6efd; }

4. Multiple Selectors

This is an h3 element

This is an h4 element

.selector-demo h3, .selector-demo h4 { background-color: #e8f4ff; padding: 6px; border-radius: 6px; }

Bonus Review: Properties and Values

A CSS rule is made of a selector and declarations. Each declaration has a property and a value.

This card uses several CSS properties together.
  • background-color changes the background
  • color changes text color
  • font-size changes text size
  • padding adds space inside
  • border adds an outline
  • text-align changes alignment
.property-demo-card { background-color: #f8f9fa; color: #222; font-size: 18px; padding: 16px; border: 2px solid #adb5bd; border-radius: 10px; text-align: center; }
