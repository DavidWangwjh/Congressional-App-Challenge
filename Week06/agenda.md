# Week 6 Agenda  

## Challenges

Today you will complete 3 webpage challenges.

For each challenge:
- first, look carefully at the look of the webpage
- then, rebuild it from scratch using HTML and CSS
- compare your webpage with the expected look
- check the solution code to see if you did anything differently

Note: It's totally fine if your code is different from the solution code. It's possible to achieve the same look with different code.

---

### Hints

Pay attention to:
- page layout
- colors
- spacing
- borders
- fonts
- alignment
- buttons
- sections

### Recommended Steps
1. Analyze the page layout and components
2. Write HTML code to set up the page structure
3. Add class or id attribute to html elements
4. Use selectors to style each element
